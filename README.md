Repositório dedicado ao armazenamento e organização de algoritmos e exercícios desenvolvidos durante as aulas no **ICMC/EESC - USP** (Campus São Carlos).

## 📌 Sobre
Este repositório contém implementações práticas em **Linguagem C**, abrangendo desde conceitos fundamentais até estruturas de dados e algoritmos lecionados na Universidade de São Paulo. O foco é a resolução de problemas académicos e o aprimoramento da lógica de programação.

## 💻 Ambiente de Desenvolvimento
Os projetos são estruturados para funcionar de forma consistente em diferentes ambientes:

* **Sistemas Operacionais:** Windows e Linux.
* **Compilador:** `gcc` (GNU Compiler Collection).

## 📂 Estrutura do Repositório
* `exercises/`: Problemas de lógica e sintaxe básica.
* `projects/`: Projetos práticos e avaliações de maior complexidade.
